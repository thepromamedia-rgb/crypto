IMPORTANT LIMITATIONS
- SMTP was not tested against a real provider. Set SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASS and SMTP_FROM, then perform a real email-delivery test before production use.
- Password-reset challenges are short-lived in-process state. A server restart invalidates pending OTP challenges; use a single application instance for this implementation.
- Wallet transfers are protected against duplicate submissions from the current UI and are serialized by the single Node event loop. The current JSON / Upstash snapshot storage is not a cross-instance transactional database. Do not scale to multiple application instances or claim multi-instance atomicity without migrating these operations to transactional storage.
- No headless browser was available for visual interaction testing. Verify desktop, tablet and mobile layouts in a real browser before release.
- Live production deployment, real SMTP, and production database backup/restore were not tested.
