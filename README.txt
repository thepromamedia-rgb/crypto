CRYPTO BRIDGE DEMO — FRONTEND STARTER

How to run:
1. Extract this ZIP.
2. Open index.html in a modern browser.

Included:
- Responsive dashboard/home page
- Quick-action buttons and bottom navigation
- Sample crypto market cards/list
- Demo popup and placeholder screens

Important:
This is a front-end-only prototype. Prices are static sample values and are not live market data. It has no real login, database, admin panel, wallet, payment, deposit, or withdrawal backend. Do not use it to collect passwords, payment details, or real funds. For a production financial app, implement secure server-side authentication, audit logs, validated payment/wallet integrations, and compliance checks under your own brand.
