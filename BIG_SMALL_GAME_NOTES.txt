BIG SMALL GAME ADDITION

- Added a separate Big Small game; existing Head Tail game remains available.
- Each round is 30 seconds and bets are rejected during the final 5 seconds.
- One shared result is selected per round using the disclosed lower-stake rule: lower aggregate Big/Small stake chooses the size; then the lowest-staked number within that size is selected. Ties are broken randomly; if there are no bets, the number is random.
- Big = 5-9; Small = 0-4.
- Color mapping: 1,3,7,9 = Green; 2,4,6,8 = Red; 0 = Red + Violet; 5 = Green + Violet.
- Big/Small and Color payout multiplier: 1.80x. Number payout multiplier: 8.80x.
- Payout multiplier is total return including the stake. Lost bets are not refunded.
- Results history and individual bet history are separate from Head Tail history.
- Outcome selection depends on aggregate wagers, so this is not an independent/random game. Make this rule clearly visible to players before accepting bets.
- This is a code update only; deployment/restart is required for the server routes to become available.
